Quiz App 🎯
A simple and interactive Quiz App built using HTML, CSS, and JavaScript. This project allows users to test their knowledge on various topics, track their scores, and receive instant feedback.

🌟 Features
✅ Multiple-choice questions
✅ Real-time score tracking
✅ Timer for each question
✅ User-friendly interface with dynamic styling
✅ Instant feedback on answers
✅ Responsive design
